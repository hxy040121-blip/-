# 开局配置

本文件各局通用。

## 1. 选角

主持人在【装载】时列出本局登场的人物卡，一到十五张。列出的先后就是各人的编号，从 1 起。同一个人的两个时间点同局时，主持人在卡名后的括号里给各人一个显示名。

## 2. 起始时刻与身体

- **T0：第一日 17:00。** 全员闭着眼，处于入场后的昏睡。
- **身体结算的起点：** 最近一次正常进食在当日 12:00，饮水在当日 14:00；最近一次睡眠是前一夜 00:00 到当日 07:00。

## 3. 醒来

登场的人坐在穹顶议事厅圆桌旁的乌木扶手椅上，一人一席，面朝桌心；编号几号就坐几号席。醒来时坐的席位，与房号、庭审座次无关。

| 席位 | 自然醒来 |
|---|---|
| 1、6、11 | 17:01 |
| 2、7、12 | 17:02 |
| 3、8、13 | 17:03 |
| 4、9、14 | 17:04 |
| 5、10、15 | 17:05 |

## 4. 身份卡

T0 时，每间套房的书桌中央平放着一张卡牌，正面朝上，正向对着书桌前的椅位。大小与游戏酒廊那六副扑克的一张相同（63×88 mm），比扑克厚而硬挺，正反两面各印一段黑字，字高约 3 mm。卡牌不可损坏：撕不开、剪不断、烧不着、泡水不坏、划不出痕，折过自己弹平。拿起或翻面各约一秒。卡上的字，在主持人给出这间房的身份之前尚未确定。

## 5. 带进来的钟表

随身带进来的钟表，走时准确的，T0 的读数与馆内各钟一致，此后各走各的。

## 6. 本局卡司

【装载】时建好 `本局卡司.md`，此后常驻，开局以后不再改动：

1. **登场者。** 每人一行：编号｜卡名｜显示名（有才写）。
2. **判定。** 一张表，每人一行，把卡上"判定"一条原样抄进去。
3. **语言与年代。** 一张表，每人一行，把卡上"语言与年代"一条原样抄进去。
