# 身体结算

身体变化由演出者自动结算，不等主持人触发。输入是时间与事件，输出是两样：**别人看得见的征象**和**本人做不到的事**。数值是普通成年人的近似基线，用来保证前后一致；各人体格与训练的差别按第 9 节调整，相同指标只算一次。表中征象表示有身体来源且可能被观察，不代表每次镜头都必须发生，也不代表其他人已观察到。认知限制只作用于当时实际任务，不给所有人配发同一句犯困的心理活动。

## 1. 起点

起始时刻（T0）每人的进食、饮水、睡眠起点按开局配置。

## 2. 饥饿（有水可喝时）

| 未进食 | 征象（他人可见） | 限制（本人） |
|---|---|---|
| 0—12 h | 无 | 无；8 h 起有饿意 |
| 12—24 h | 偶尔走神、易怒；一眼看不出，停看能见疲态 | 无实质限制；耐心差，容易被激 |
| 24—48 h | 脸色差，起身时扶一下，说话省字 | 持续体力活每二十分钟要歇五分钟；复杂推理慢一半 |
| 48—72 h | 手抖，站久了晃，嗜睡，冷 | 不能做持续体力活；上下楼要扶；争执时容易放弃 |
| 72 h—5 d | 大部分时间躺着，反应慢，冷漠 | 走动只限同层短距离；细致观察与记忆明显出错 |
| 5 d 以上 | 起身困难，意识模糊 | 基本失去行动能力；有水时两周内通常不死 |

进食后一到两小时回升一档，一顿正常饭回到 0—12 h 档；少量食物只延缓，不回档。

## 3. 口渴（无水时）

| 未饮水 | 征象 | 限制 |
|---|---|---|
| 0—12 h | 无 | 无 |
| 12—24 h | 口干，嗓音哑，头痛 | 注意力差；体力活减半 |
| 24—48 h | 唇裂，尿少，站起时眼前发黑 | 不能做体力活；判断力明显下降 |
| 48—72 h | 意识混乱，脉快 | 只能躺卧 |
| 72 h 以上 | 昏迷风险 | 死亡进入结算 |

喝到水后一小时内回升一档。

## 4. 失眠

| 连续清醒 | 征象 | 限制 |
|---|---|---|
| 0—18 h | 无 | 无 |
| 18—24 h | 打哈欠，眼红，反应慢半拍 | 连续阅读、计数与记对应关系更易遗漏 |
| 24—36 h | 说话颠倒，坐下就发怔，脾气坏 | 独自静坐，十五分钟内必然睡着，除非手上一直在做事；反应时间翻倍 |
| 36—48 h | 微睡：站着也会闭眼几秒；看错、听错 | 不能可靠守夜；推理链超过三步就断 |
| 48 h 以上 | 强制入睡：任何静止状态五分钟内睡着；可能幻听 | 无法完成任何需要连续注意的事 |

睡四小时回升一档，睡七小时回到 0。冷、湿、地面、有人来往，每项让一次睡眠少算一小时。

## 5. 失温

馆内室温约 22 ℃，穿干衣不失温。下表只适用于所列水温、气温与暴露方式；约 28 ℃ 的池水不直接套用 16—18 ℃ 冷水浸泡时程：

| 处境 | 时间 | 征象 | 限制 |
|---|---|---|---|
| 衣服湿透，站在 22 ℃ 的空气里 | 30 min | 发抖 | 手指精细动作变差 |
| 同上 | 2 h | 抖得说话断续，嘴唇发青 | 拧不开瓶盖、系不上扣子；记忆与判断开始出错 |
| 同上 | 6 h 以上 | 抖停了，反应迟钝，站不稳 | 意识混乱；死亡进入结算 |
| 持续淋 16—18 ℃ 的水 | 10—15 min | 发抖 | 精细动作变差 |
| 同上 | 30—45 min | 手基本不听使唤 | 做不了任何需要手指的事 |
| 同上 | 1—2 h | 动作笨拙，说话含混 | 走路要扶；推理断 |
| 同上 | 3—5 h | 意识混乱，跌倒 | 只能躺 |
| 同上 | 6—10 h | 昏迷 | 死亡进入结算 |
| 浸在 16—18 ℃ 的水里 | 按"持续淋 16—18 ℃ 的水"各档，时间减半 | | |

脱下湿衣、裹毛毯、待在 22 ℃ 室内：轻度一小时内回复，中度三小时，重度需数小时并有人照看。离水、换房或保暖后按实际环境和湿衣状态继续结算，已发生的身体变化不重置。有遮挡但地面积水、衣服仍湿，且环境符合上表条件时，按第一组计。

## 6. 外伤

| 伤 | 当场 | 之后 |
|---|---|---|
| 浅割伤（玻璃、瓷片） | 出血几分钟，压住即止；疼 | 手上的伤影响握持与精细动作一到两天；不处理，一两天后发红肿痛 |
| 深割伤（刃具、深玻璃） | 出血多，要持续压迫或扎紧；不处理，三十到六十分钟后虚弱、脸白 | 大血管（颈、腋、大腿内侧）不处理数分钟内死亡进入结算；四肢深伤不处理一到三小时内昏迷；处理后两三天内该肢不能用力 |
| 钝伤（拳、球、家具） | 疼，肿，该处不能用力 | 一周 |
| 重钝器（哑铃、扳手、铁锹、撬棍类，双手挥击） | 击中四肢：骨折概率高；击中躯干：肋骨骨折、内出血，当场倒地，数小时内可能死亡进入结算；击中头部：昏迷起步，多次或全力击打死亡进入结算 | 头部重击存活者按脑震荡以上计，数日内不能可靠行动 |
| 脑震荡（头部重击、摔倒磕头） | 短暂失神或昏迷数秒到数分钟；醒后恶心、头晕、想睡 | 十二到二十四小时内反应慢、记忆缺、不能可靠推理；再受一次重击危险 |
| 骨折（坠落、重物、扭打） | 剧痛，该肢不能承重或抓握 | 数周；无固定物只能自制夹板 |
| 昏迷（击打） | 几秒到几分钟；超过十分钟不醒就是重伤 | 醒后按脑震荡计 |

疼痛：受伤后前几分钟肾上腺素掩盖，之后疼痛使该部位的动作减半、注意力被占。

## 7. 窒息、勒颈、坠落

- **扼颈或勒颈**：完全压迫气道或颈动脉，十到二十秒失去意识；一分钟内松开，通常数分钟内醒来，颈部留痕、声音嘶哑；持续两到四分钟，死亡进入结算。前二十秒能挣扎，体格差距决定挣扎有没有用。
- **闷压口鼻（枕头、毛毯）**：挣扎一到两分钟；两到三分钟失去意识；四到六分钟死亡进入结算。
- **坠落到硬地**：一米内，擦伤；一到二米，扭伤或骨折可能；二到五米，骨折概率高，头先着地则脑震荡或更重；五米以上，重伤，死亡进入结算。落到软物或有人接住，减一档。
- **落物**：按重量与高度；十公斤以上从两米落到头上，脑震荡起步。
- **溺水**：口鼻露不露得出水面，看实际的水深、浅水台阶、池岸和抓得到的东西；站得稳、能呼吸的人，不会因为下了水就溺水。水深过顶、又抓不到东西时，会游泳的人撑得住几分钟或更久，不会游泳的三十秒到一分钟内开始呛水。呼吸持续受阻，清醒的人二十到六十秒失去意识，两到四分钟死亡进入结算。落水之前已经昏迷、缺氧、受伤或行动受限的，照原来的状态接着算：时间不因落水从头计，做不到的动作在水里照样做不到。离了水，呼吸、意识和行动不会自己恢复，此前的损伤也还在，按受阻多久、身体状态和实际救助结算，重大结果按第 11 节。湿冷另按第 5 节。

## 8. 体力与疲劳

| 活动 | 普通人 |
|---|---|
| 提二十公斤重物上一层楼 | 一趟约三分钟，六趟后要歇 |
| 搬一件二十公斤的家具 | 每件约二十秒，连续搬十几件要二十到三十分钟，中途歇一次 |
| 挖三十厘米深的土 | 十分钟，之后手臂酸 |
| 全力扭打 | 一到两分钟耗尽；之后五到十分钟无法再全力 |
| 抬起一个失去意识或不配合的成年人 | 需要两人；一人只能拖 |
| 持续快走一小时 | 可以；之后腿酸 |

疲劳叠加饥饿、失眠、失温：取最重的一档，再降一档。

## 9. 相对身体修正

各人属于哪一类，看人物卡"本局适配"里的"身体"一条，和"判定"一条中的"体能与格斗"。每项只算一次。

- 体能强、受过训练：耐受时间 ×1.3—1.5；扭打持续时间 ×2；体力活耗时 ×0.8。
- 体能弱、久坐、瘦小：耐受时间 ×0.6—0.8；体力活耗时 ×1.3；坠落与钝伤加一档。
- 六十岁以上：失温、饥饿、失眠的耐受 ×0.7；骨折概率高一档；恢复时间 ×1.5。
- 身材明显小于成人：失温、饥饿 ×0.7；扭打中体格差距按重量比结算。
- 已受伤、已中度以上任一状态：其余所有耐受 ×0.8。

卡上写明的耐痛与硬撑，只用来算疼痛导致的行动中断；实际组织损伤、失血或其他致死进程按真实物态继续。

## 10. 中毒、药物、酒与主持人定义的效果

本节不另定义毒物或药物。物理层定义的药物和主持人游戏定义的效果，按各自的定义执行；定义没写到的（被打断的剂量、混合、体重差异）按运行规则 1.2 甲项交给主持人。

**兑换来的药。** 安眠药与药柜里的同效。强效止痛药起效和时长同药柜的止痛片，四小时内疼痛不再妨碍行动；伤本身照旧，该肢不能用力的仍然不能用力；过量同样只引起胃痛、呕吐。抗生素、输血按常识结算，伤者的生死仍按第 11 节。广谱解毒剂：别处有定义的毒照定义；没有定义的中毒，管不管用、救不救得回，按运行规则 1.2 甲项交给主持人。

**酒。** 一杯指一罐啤酒、一杯葡萄酒（约 150 ml）或一小杯烈酒（约 40 ml）。酒意大约每小时退去一杯，所以按体内的杯数算：喝下的杯数，减去从开始喝到现在的小时数。按体格普通、平时喝酒的成年人：

- 两三杯：微醺，话多，放松，判断略松。
- 四到七杯：走路不稳，反应慢，手上不准，事后记忆会断片。
- 八到十一杯：呕吐，昏沉，叫得醒，醒了也不清楚。
- 十二杯以上：叫不醒；仰躺着可能被呕吐物呛住，按第 11 节进入死亡结算。喝到这一步之前，旁人早就看得出他在往死里喝。

卡上写明酒量好的，按轻一档算；很少喝酒的、空腹的、瘦小的，按重一档算，几项都占的最多重两档，不再套第 9 节的倍数。卡上没写的，成年人按平时喝酒算，原作里还是学生或未成年的按很少喝酒算。规则宣告之后，有戒心的人不在信不过的人面前喝醉（运行规则 4.2、4.3）。

酒和安眠药：和一两杯酒一起下肚，药效来得快一些，人更难弄醒；危险只来自酒本身喝到的那一档。

## 11. 死亡与失能

- **失能**：本人无法站立或无法完成任何有目的的动作。失能者仍能感知、能说话（除非昏迷），能被移动。
- **死亡进入结算**：抵达相应风险区间时，根据已发生的伤害、持续时间和实际救助判断生死；结果不确定时按运行规则 5.3 做一次写明依据的判定。确定死亡的，登记实际时刻。主持人的救助或改变作为明确介入另行登记。
- 死亡后的体温、僵硬、尸斑及冷热环境的干扰，按物理层 7.4；其余变化按常识。

## 12. 记账

湿冷、伤与受伤时刻、偏离平时的档位，有才记进续接记录（运行规则 9.2）。征象进入他人知识的难易：发抖、脸白、站不稳，一眼可见；手抖、说话省字，要停下来看；脉搏、伤口深浅要触摸或检查。
