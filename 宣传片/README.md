# 重新生成

```bash
./build.sh            # 字体 → 配乐 → 逐帧渲染 → 合成，输出 夙与愿_宣传片.mp4 与 30 MB 以内的分享版
```

依赖：python3（numpy、scipy）、node + playwright（Chromium）、ffmpeg。

| 文件 | 作用 |
|---|---|
| `timeline.json` | 节拍（100 BPM）、字幕、事件，画面与配乐共用，改这里两边同步 |
| `scene.js` / `scene.html` | Canvas 画面，`renderFrame(t)` 逐帧确定性绘制 |
| `render.js` | 无头 Chromium 渲染，`stills <拍…>` 导出单帧预览，`video` 渲染全片 |
| `music.py` | 合成配乐与音效，输出 `build/music.wav` |
| `fetch_fonts.sh` | 下载 Noto Serif SC、Noto Sans SC、Cinzel（均为 OFL 开源授权） |
